# Flip & Learn – Flashcards Quiz App

A fun, interactive flashcards quiz web app built using HTML, CSS, and JavaScript. The app helps users test and improve their JavaScript knowledge through multiple-choice questions and a dynamic flip card interface.

## Requirements
[Watch the project recording at] (https://www.loom.com/share/0d64573026984004bf20938003f178b4)

## Problem Statement
Learners sometimes struggle to retain information through passive reading and lack of interactivity,quick feedback and personalization leading to decreased motivation.

## Solution
Flip & Learn offers a visually engaging way to reinforce JavaScript concepts. With a card flip animation, multiple-choice interaction, real-time feedback, and scoring, learners are encouraged to stay engaged and improve their knowledge progressively.

## Features

- Card Flip Animation: Flashcards flip to reveal the correct answer after a selection is made.
- Multiple Choice Questions: Each card presents a question with answer choices. Users must select one before proceeding.
- Answer Feedback: Immediate visual feedback indicating correct or incorrect answers.
- Score Tracking: Displays total correct answers and performance message at the end.
- Theme Toggle:** Switch between light and dark mode for user comfort.

##  Technologies Used

- HTML5
- CSS3 (Flexbox, Animations)
- JavaScript (DOM, fetch API)
- JSON Server for local backend simulation

## 🚀 How to Run

1. Install [JSON Server](https://github.com/typicode/json-server) globally if not already: then run this npm install -g json-server
2. Start the server:
json-server --watch db.json
3. Open `index.html` in your browser.
